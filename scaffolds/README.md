# Scaffolds

Optional. Each one boots an HTTP server on port 3000 with the service base URLs
in config and nothing else. They exist so you do not spend the first ten minutes
on project setup.

Every scaffold uses only its language's standard library, so none of them need a
package install to run. Add whatever framework you prefer.

| Language | Run |
|---|---|
| TypeScript / Node | `cd typescript && node server.mjs` |
| Go | `cd go && go run .` |
| Python | `cd python && python3 server.py` |
| C# | `cd csharp && dotnet run` |
| Java | `cd java && java Server.java` |

Delete the ones you are not using.
